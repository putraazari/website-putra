# 🚀 Putra Azari - Analisa Teknologi & Sains

Selamat datang di **Putra Azari**, sebuah platform analisis teknologi dan sains yang mencakup:

## 📡 Topik Utama

| # | Topik | Deskripsi |
|---|-------|-----------|
| 1 | **GSM Network Analysis** | Arsitektur BSS/NSS, spektrum frekuensi, keamanan A5/A3 |
| 2 | **Cloud VPS Tracking** | Infrastruktur cloud, GPS tracking server, data pipeline |
| 3 | **Tracking Systems** | GPS/GNSS, IoT tracking, vehicle & asset tracking |
| 4 | **Signaling SS7** | SS7 protocol stack, security analysis, topology |
| 5 | **Horizontal Geography** | Geospasial, kartografi digital, GIS modern |
| 6 | **Fisika Kuantum** | Superposisi, entanglement, quantum computing |

## 🛠️ Teknologi

- **HTML5** - Semantic markup
- **CSS3** - Modern layout (Flexbox, Grid), animations, responsive design
- **JavaScript** - Interactive features, animations, quantum calculator
- **Particles.js** - Dynamic particle background
- **Font Awesome 6** - Icons
- **Google Fonts** - Orbitron & Inter typography

## 🚀 Cara Menjalankan

1. Buka file `index.html` di browser modern (Chrome, Firefox, Edge)
2. Atau jalankan dengan live server:
   ```bash
   npx serve .
   ```
